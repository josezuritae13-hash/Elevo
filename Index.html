      INSTALACIÓN PASO A PASO

      Cómo instalar la extensión

      La instalación se hace una sola vez en Google Chrome.

      01
      ↓

      Descarga el archivo

      Pulsa el botón de descarga de esta página. Se guardará un archivo ZIP en tu computadora.

      Descargar ZIP ↗
      02
      ▧

      Extrae el ZIP

      En Windows, abre Descargas, haz clic derecho sobre el ZIP y selecciona «Extraer todo…». No cargues el ZIP directamente en Chrome.

      Debe quedar una carpeta con manifest.json.
      03
      ⚙

      Abre las extensiones

      En Chrome, escribe chrome://extensions en la barra de direcciones y presiona Enter.

      Activa «Modo de desarrollador».
      04
      ＋

      Carga la carpeta

      Pulsa «Cargar descomprimida» y selecciona la carpeta que extrajiste, donde se encuentra directamente manifest.json.

      No selecciones el ZIP ni una carpeta exterior vacía.
      05
      ↻

      Recarga Idukay

      Abre Idukay, inicia sesión y recarga la pestaña después de instalar la extensión para que Chrome la pueda usar.

      Puedes fijar Elevate desde el menú de extensiones.
      06
      ✓

      ¡Ya está instalada!

      Abre el icono de Elevate desde Chrome y pulsa «Copiar mis notas» para generar el JSON.

      DESPUÉS DE INSTALAR

      Cómo utilizarla

      El recorrido completo desde Idukay hasta tu panel académico.

      1. 1
        Entra a Idukay

        Inicia sesión normalmente y deja abierta la pestaña.

      2. 2
        Abre Elevate · Idukay

        Selecciona la extensión desde el icono de piezas de Chrome y pulsa «Copiar mis notas».

      3. 3
        Vuelve a Elevate

        Entra en «Importar de Idukay» y pega el JSON que se copió al portapapeles.

      4. 4
        Revisa antes de importar

        Comprueba materias, nombres, fechas y trimestres. Confirma solo cuando todo esté correcto.

      i
      Importante sobre esta instalación

      Esta descarga instala la extensión localmente mediante el modo de desarrollador de Chrome de escritorio; no es una publicación de Chrome Web Store y no se puede instalar dentro de Chrome para móviles. La extensión necesita una sesión activa de Idukay y depende de la compatibilidad de su plataforma. Si Idukay cambia su API o la versión requerida, la extracción podría dejar de funcionar hasta actualizar la extensión.
